# 口语交际比赛项目规划 v2

> 基于原有「认一认v1」扩展，新增「辨一辨」「说一说」两大环节，形成完整的三环节比赛系统。

---

## 一、项目概述

### 定位
教师端大屏展示系统，供课堂比赛使用。学生上来展示，教师实时评分，全班可见。

### 核心流程

```
选择年级段 → 选择环节 → 开始比赛 → 实时评分 → 结果统计
```

---

## 二、三环节设计

---

### 环节一：认一认

**功能：** 展示图片，学生说出名称，教师评分

**继承自v1的核心逻辑：**
- 图片随机滚动 → 停止 → 显示题目
- 1-4分评分按钮
- 支持多题连续进行

**界面要素：**
- 大标题：「认一认」
- 物品图片（大屏居中，400×400px以上）
- 题目编号（第 X 轮，共 X 轮）
- 评分按钮组：4分 / 3分 / 2分 / 1分
- 当前学生信息

---

### 环节二：辨一辨

**功能：** 连连看/分类题，学生找出同类物品

#### A. 连连看题型（中低年段）
- 左侧：3-4个物品图片
- 右侧：3-4个物品名称（打乱顺序）
- 学生说出配对关系，教师点击连线

#### B. 分类题型（高年段《我们的住房》用）
- 展示一个房间场景
- 拖拽物品到正确区域（客厅/卧室/厨房/卫生间）

**界面要素：**
- 大标题：「辨一辨」
- 题干说明
- 左侧：待分类物品
- 右侧：目标区域
- 连线动画效果

---

### 环节三：说一说

**功能：** 看图说话，练习句型

#### 中低年段《好吃的水果》
- 展示水果图片
- 引导句型：「什么大？什么小？」
- 示例：「苹果大，樱桃小。」

#### 高年段《我们的住房》
- 展示房间场景图
- 引导句型：「谁在哪里做什么？」
- 示例：「妈妈在厨房做饭。」

---

## 三、通用功能

- 年级段切换（中低/高年段）
- 学生信息管理
- 结果统计页
- localStorage 持久化

---

## 四、技术实现

- React 17 + Babel 单文件
- 原生 HTML/CSS/JS
- 无需构建工具，直接浏览器打开

---

## 五、开发优先级

| 优先级 | 模块 | 说明 |
|--------|------|------|
| P0 | 认一认 | 复用v1逻辑，优化UI |
| P1 | 年级/环节切换 | 架构核心 |
| P2 | 辨一辨（连连看） | 新功能 |
| P3 | 辨一辨（分类） | 拖拽交互 |
| P4 | 说一说 | 句型模板 |
| P5 | 结果统计 | 数据聚合 |

## 六、待确认问题

1. **辨一辨的交互方式**：教师点击连线，还是学生触屏操作？
2. **说一说的评分标准**：是否需要录音回放？
3. **题库来源**：图片是教师上传还是内置？
4. **比赛流程**：三个环节是必须依次进行，还是可以自由选择？
