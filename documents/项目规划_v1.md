| 文件 | 用途 |

| admin.html | 后台管理（年段、题库、学生） |
| index.html | 上课模式（比赛、点名、统计） |

---

## 三环节设计

### 环节一：认一认
- 大屏展示图片，学生说名称
- 教师评分：3分 / 2分 / 1分 / 0分

### 环节二：辨一辨
- 上方：1张大图（题目）
- 下方：3个选项图片，学生点击选择
- **随机组合逻辑**：
  - 从大图中随机选1张作为题目
  - 从小图中随机选1张作为正确答案
  - 从剩余小图中随机选2张作为错误选项
  - 3个选项打乱顺序显示
- 答对3分，答错0分

### 环节三：说一说
- 大屏展示图片，学生自由描述
- 教师评分：3分 / 2分 / 1分 / 0分

---

## 比赛流程

```
选择年段 → 随机点名 → 认一认(1题) → 辨一辨(1题) → 说一说(1题) → 显示总分(满分9分)
                                              ↓
                                    继续下一位 / 查看统计
```

## 后台配置说明

### 认一认
- 上传 N 张图片
- 系统随机抽取

### 辨一辨
- 上传 N 张大图（题目图）
- 上传 M 张小图（选项图，至少3张）
- 系统自动随机生成题目（1大图+1正确小图+2错误小图）

### 说一说
- 上传 N 张图片
- 系统随机抽取

### 学生列表
- 添加学生姓名（支持回车添加）
