# 口语交际比赛系统

教师端大屏展示系统，供课堂比赛使用。

## 项目结构

```
speech-contest/
├── documents/          # 项目文档
│   └── 项目规划_v1.md
├── src/               # 源代码（待创建）
└── README.md
```

## 三环节

1. **认一认** — 图片识别，说出名称
2. **辨一辨** — 连连看/分类
3. **说一说** — 看图说话，练习句型

## 技术栈

- React 17 + Babel
- 单文件 HTML，无需构建
